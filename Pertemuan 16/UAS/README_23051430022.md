## Deskripsi
Aplikasi manajemen gudang berbasis React Native + Expo yang memiliki fitur:

- Daftar barang gudang dengan informasi stok dan lokasi rak
- Pencarian barang berdasarkan nama secara real-time
- Pengurutan daftar barang A-Z (toggle sort)
- Indikator stok kritis (merah) dan stok aman (hijau)
- Halaman detail barang dengan informasi lengkap
- Update stok secara interaktif (tambah / kurang)
- Peringatan otomatis saat stok kritis (< 5 unit)
- Navigasi antar halaman menggunakan React Navigation

## Cara Menjalankan Project

1. Extract file `Pertemuan_16.zip`

2. Masuk ke folder project

```
cd "Pertemuan 16/UAS"
```

3. Install dependency

```
npm install
```

4. Jalankan project

```
npm start
```

5. Pilih platform:

   - Tekan `a` untuk membuka di Android Emulator
   - Tekan `i` untuk membuka di iOS Simulator
   - Scan QR code menggunakan aplikasi **Expo Go** di perangkat fisik
