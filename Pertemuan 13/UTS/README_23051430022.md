## Deskripsi
Aplikasi laporan produksi berbasis React + Vite yang memiliki fitur:

- Input laporan produksi
- Validasi input
- Dashboard KPI produksi
- Riwayat data
- Hapus data
- Hapus semua data
- Penyimpanan LocalStorage

## Cara Menjalankan Project

1. Extract file SOURCE_CODE_NIM.zip

2. Buka terminal pada folder project

3. Install dependency

npm install

4. Jalankan project

npm run dev

5. Buka browser

http://localhost:5173/

## Teknologi

- React
- Vite
- React Router DOM
- Bootstrap 5
- LocalStorage
